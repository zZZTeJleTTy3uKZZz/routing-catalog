# Каталог назначений

Списки доменов, адресных диапазонов и имён программ для настройки маршрутизации трафика.
Данные версионируются, публикуются релизом и подтягиваются клиентами по ссылке.

## Файлы

| Файл | Что внутри |
|---|---|
| `catalog/local-limited.json` | ресурсы, недоступные с нашей стороны |
| `catalog/remote-limited.json` | ресурсы, не принимающие наши адреса |
| `schema.json` | схема каталога (JSON Schema) |
| `scripts/build.py` | проверка по схеме и сборка наборов |

## Формат записи

`id`, `title`, `domains` (с поддоменами), `ip_cidr`, `apps` по платформам
(`windows`, `linux`, `android`, `macos`) и обязательное `source` - откуда взята запись.

## Релиз

Каждый релиз содержит для каждого списка:

- `<список>.json` - каталог;
- `<список>.rules.json` - домены и диапазоны в виде набора правил;
- `<список>.<платформа>.rules.json` - имена программ платформы;
- `.sha256sum` рядом с каждым файлом.

Последняя версия: `https://github.com/zZZTeJleTTy3uKZZz/routing-catalog/releases/latest/download/<файл>`.

## Как пополнить

Добавьте запись в нужный `catalog/*.json`, поднимите `version`, откройте запрос на слияние.
Проверка схемы и сборка выполняются автоматически.
